# Long-lived collections outside src/mem that the guard (tests/it/mem_guard.rs) accepts. Format:
#   path under src | symbol | bound | reason
# The bound says what stops the growth. "registry follow-up" marks a holder that is bounded today by its own cap but should move
# onto the memory registry (mem::BoundedCache / mem::Budget) so `status --memory` shows it. Verified against the code on 2026-10-10.
