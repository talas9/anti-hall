# Long-lived collections outside src/mem that the guard (tests/it/mem_guard.rs) accepts. Format:
#   path under src | symbol | bound | reason
# The bound says what stops the growth. "registry follow-up" marks a holder that is bounded today by its own cap but should move
# onto the memory registry (mem::BoundedCache / mem::Budget) so `status --memory` shows it. Verified against the code on 2026-10-10.

# ---- bounded by a cap read from config, own eviction (registry follow-ups) -------------------------------------------------
checks/agent_scan/mod.rs | KEPT | entry cap read at insert (`while map.len() >= cap`, line ~1255); entries are transcript walks | kept transcript walks; registry follow-up (the agent_scan job owns the file), clone-on-answer is audit item 8
daemon.rs | Shared.queue | accept queue cap (daemon.queue): a full queue answers busy | the connection queue; bounded by the cap, not a cache
db.rs | Mem.kv | registered as mem.db_kv_* and also constrained by tier.budget_kb in Tiered | active key-value items; SQLite remains the source of truth
gitcache/mod.rs | GitCache.repos | gitcache.max_repos, idle entries expire after gitcache idle_ttl | memoised git state per repository
hookcfg/session.rs | SessionCore.slots | registered as mem.hook_sessions_*; expired counters are pruned even without SessionEnd | per-session hook condition counters
limits.rs | BucketCore.map | registered through aggregate mem.buckets_* holder | daemon session/project rate buckets
limits.rs | BucketOwners.buckets | weak references to live registered bucket maps, stale entries removed on access | aggregate owner list for mem.buckets_*
load.rs | Load.minutes | newest load.minutes_kept buckets, each bucket capped | per-minute request load
tier.rs | Bus.subs | max_channels channels and a bounded queue per subscriber | pub/sub channels
transcript/registry.rs | Indexes.slots | `max` slots, entries expire after ttl_ms (cfg) | transcript index slots; registry follow-up (transcript caches belong to another job)
devswarm_rt/reconcile.rs | Rt.edges | cfg.edge_cap edges (pop_front past it) | recent state edges; count-capped, not byte-capped (audit item 5, follow-up)
schedule.rs | Scheduler.state | one entry per configured job (schedules.toml), fixed at load | job state
schedule.rs | Scheduler.last | one entry per configured job | last-run state
ghrt/repos.rs | NOTED | entries older than ttl dropped once past cap (arguments of note()) | recently noted working directories
watch/mod.rs | Shared.polled | one entry per watched directory that falls back to polling; the watch set is bounded by the callers' own lists | realtime watch fallback
watch/notify.rs | Events.dirs | one entry per watched directory | realtime watch translation table
dsact/events.rs | Dirty.set | one entry per workspace marked dirty; drained once quiet for the debounce | DevSwarm auto-archive debounce
dsact/events.rs | IN_FLIGHT | one id per in-flight workspace trigger, removed on drop | in-flight lock set
jev/shared.rs | LANES | one lane per Jev home directory (a handful per machine) | Jev lanes (audit item 10, follow-up)
jev/assist.rs | JevStats.calls | keyed by (backend, mode) labels from code | drained by the periodic flush

jev/assist.rs | JevStats.latencies_us | one u64 per ask between flushes | drained by the periodic flush
devswarm_rt/sources.rs | FsProbe.plans | one entry per workspace plan file; the probe lives for one reconcile | built once per probe
