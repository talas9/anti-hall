# Features

<div class="grid cards" markdown>

- :octicons-shield-check-16: **[Guards and checks](guards.md)**

    Stops force-pushes, AI credit lines, unchecked claims and runaway agents.

- :material-format-list-checks: **[Task tracking](tasks.md)**

    A task list the assistant must keep honest before it stops.

- :material-file-restore: **[Handovers and context](handovers.md)**

    A handover file at 85% context, so a fresh session loses nothing.

- :material-tools: **[Skills](skills.md)**

    Named workflows you can call: root-cause, deadly-loop, ship-it and more.

- :material-gauge: **[Statusline](statusline.md)**

    Project, git state, model, context use and agent activity in two lines.

- :material-source-branch: **[DevSwarm workspaces](devswarm.md)**

    Supervision and recovery for parallel workspaces.

</div>

These features all run on anti-hall's Rust engine, the core component. See
[How it works](../how-it-works/index.md).

!!! note "Claude Code and Codex"
    Every feature ships for both. Where an example differs, it is shown in tabs.
