# Getting help

anti-hall is maintained by one person (Mohammed Talas, [@talas9](https://github.com/talas9)) in spare time. There is no paid support or response-time guarantee.

## Where to go

| You want to… | Go to |
|---|---|
| Install, configure or turn off a guard | [`docs/GUIDE.md`](docs/GUIDE.md) and the [documentation start page](docs/README.md) |
| Check that anti-hall is working | Run `/anti-hall:doctor` in Claude Code |
| Ask a question or suggest an idea | [Discussions](https://github.com/talas9/anti-hall/discussions) |
| Report a bug or a guard that blocked something legitimate | [Open an issue](https://github.com/talas9/anti-hall/issues/new/choose) and pick the matching template |
| Report a security problem | Privately, as described in [`SECURITY.md`](SECURITY.md); never in a public issue |

## Before you open an issue

- Update first (`/anti-hall:update`) and check that the problem still happens on the latest version.
- Search existing issues and discussions.
- Include the anti-hall version, whether you use the Claude plugin or the Codex port, your OS and Node.js version, and the exact input and output. Remove secrets, tokens and personal paths.
